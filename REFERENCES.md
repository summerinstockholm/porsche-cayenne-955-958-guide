Уровень после замены всегда выставляется по штатной процедуре автомобиля.

### Методика

1. Живые объявления по РФ.
2. Дедупликация одной машины между площадками, где её можно уверенно определить.
3. Без искусственного разделения на «дилер» / «частник».
4. Исключаются проекты, битые/не на ходу, нерастаможенные, «под заказ», а также условные кредитные/трейд-ин цены без понятной обычной цены продажи.
5. Учитываются год, пробег, версия двигателя, владельцы и цена.
6. Анализируется распределение, а не абсолютный min/max.
7. Низ/ядро/верх рынка проверяются отдельно.
8. Крайние значения читаются вручную и интерпретируются по состоянию/истории.

### Ограничения

- Цены — **asking prices**, не подтверждённые цены сделок.
- Avito заметно хуже Auto.ru/Drom отдаёт полный публичный индекс, поэтому невозможно честно утверждать, что в машинный срез попала каждая карточка площадки.
- Для редких Turbo S, S Diesel и Hybrid выборка маленькая; диапазоны у них менее статистически устойчивы.
- Ценовые зоны в README предназначены для первичной фильтрации рынка, а не для оценки конкретного VIN без осмотра.
