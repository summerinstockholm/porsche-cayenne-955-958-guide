# Changelog

Все заметные изменения проекта фиксируются здесь.

## [1.2] — 2026-09-13

### Добавлено

- большой блок **«Рынок РФ — сентябрь 2026»** для каждого поколения и каждой основной модификации;
- ценовые зоны: **подозрительно дёшево → низ рынка → нормальный рынок → хороший экземпляр → верх рынка**;
- пояснения, за что стоит доплачивать и когда низкая цена не является выгодой;
- компактная таблица **«Какой Cayenne покупать»**;
- короткий полевой PPI-чеклист для осмотра автомобиля с телефона;
- `REFERENCES.md` с техническими и рыночными источниками;
- методика анализа рынка Auto.ru / Avito / Drom.

### Уточнено

- Porsche-код АКПП **958 GTS 4.8 420: A48.04**; A48.05 относится к 958.2 GTS 3.6 biturbo;
- обозначение двигателя 955 Turbo S 521: в каталогах встречаются **M48.50S / M48.50T**;
- для S Diesel 4.1 разведены сервисный объём замены и **10.2 L полного объёма масляной системы**;
- для российского **958.2 Diesel MCR.CA 245** уточнён сервисный объём масла: ориентир **≈7,3 л с фильтром**; значение около 7,7 л относится к другим поздним европейским 3.0 TDI (MCV.VA/VB) и не переносится автоматически на MCR.CA;
- экологический класс российского 958.2 Diesel MCR.CA 245: рабочий ориентир **Euro 5**, финальная юридическая проверка — по документам конкретного VIN;
- дополнительно закреплено различие между заводскими длинными интервалами Porsche и практическими интервалами возрастной машины.

### Оптимизировано

- `fetch-images.sh` теперь после загрузки уменьшает реальные Wikimedia-фотографии до максимальной стороны 1600 px и JPEG quality 82 через встроенный macOS `sips`;
- фотографии остаются теми же Public Domain / CC0, генеративные изображения не используются.
